{% comment %} Shared filter panel for the event list and map pages. Required context: - filter_form_id (str): id for the wrapping

Optional: - show_when_filter (bool): renders the upcoming/past toggle (list view only). When omitted/false, the date_from input no longer special-cases show_past. - show_past, upcoming_count, past_count, date_range_active: required when show_when_filter is true. Layout: an always-visible quickbar (This week / Next week date chips + the "More filters" disclosure toggle + a Clear text link) with a collapsible panel (search, when, category, publisher, date range incl. This weekend/This month/Next month chips, is_free, wheelchair accessible) below it. The disclosure's open/closed state is view-computed (advanced_filters_open) rather than duplicated in template conditions, since only filters that live inside the panel should force it open. would make the details element itself grow to the panel's full width when open, which visually relocates the "More filters" toggle chip out of the quickbar row. Keeping
